# 한국 쇼핑몰 리뷰 크롤링 법적 검토 메모 (2026-10-08)

> **법률 자문이 아닙니다.** 웹 검색으로 모은 2차 자료(법무법인 뉴스레터, 언론, 해설 글)를 정리한 것이고, 판결문·법령·약관 원문은 직접 확인하지 못했습니다.
> 네이버 약관은 이 환경에서 접근이 막혀 열어 보지 못했습니다. robots.txt는 사용자가 붙여 넣은 내용을 1-1에 반영했습니다. **아래 "확인 필요"로 표시한 항목은 사람이 원문을 확인해야 합니다.**

## 목적과 전제
- 학습 프로젝트(비상업)에서 한국어 감성 모델을 만들려는데 한국어 이커머스 리뷰가 없다. 네이버 쇼핑 등 한국 쇼핑몰 리뷰를 크롤링해도 되는지 검토한다.
- 사용 범위는 모델 학습·평가이고, 원문 재배포는 계획하지 않는다고 가정했다.

## 결론 (요약)
1. **직접 크롤링은 권하지 않는다.** "비상업·학습 목적"이라는 사정은 저작권 쪽에서만 유리하게 작용하고, 약관 위반이나 접근 방식 문제는 목적과 상관없이 남는다.
2. **가장 안전한 순서:** ① 직접 만든/합성한 한국어 리뷰 → ② 이용 조건이 명확한 공개 데이터(AI Hub 등) → ③ 플랫폼의 허락을 받은 데이터 → ④ (비권장) 직접 크롤링.
3. 평가셋(300~500건)이 목적이면 크롤링 없이도 가능한 방법이 많다. 아래 "대안" 참고.

## 쟁점별 검토

### 1. 이용약관 / 접근 방식 (가장 현실적인 위험)
- 네이버 이용약관이 자동화된 프로그램으로 게시물을 수집하는 것을 금지한다는 설명이 있다(검색 결과의 2차 설명. **약관 원문 확인 필요**).
- 네이버가 이용자 생성 콘텐츠의 AI 크롤링을 기본 차단하고 있다는 보도가 있다([아주경제](https://www.ajunews.com/view/20241006171154905), 확인 필요).
- 약관 위반은 비상업 목적이어도 계정 제재, 민사상 책임(채무불이행·불법행위) 등으로 이어질 수 있다. 로그인·차단 우회, 과도한 요청으로 서버 부담을 주는 경우는 더 위험하다(일반적인 법리, 확인 필요).

#### 1-1. 네이버 robots.txt 확인 (2026-10-08, 사용자가 붙여 넣은 내용)
출처 도메인은 "네이버"로만 전달되었고(쇼핑 계열로 보임) 제가 직접 가져온 것은 아니라서, **어느 도메인의 파일인지와 현재 내용은 사람이 한 번 더 확인**해야 한다. 붙여 넣은 내용 기준:
- 파일 맨 위에 "AI 학습 및 RAG 목적의 봇 접근을 엄격히 금지한다"는 명시적 문구가 있다.
- GPTBot, ClaudeBot, Google-Extended, CCBot 등 AI 크롤러를 이름으로 전부 차단(`Disallow: /`)했다.
- `User-agent: *`(그 밖의 모든 크롤러)도 `Disallow: /`라서, 직접 만든 크롤러는 예외 없이 **전체 금지** 대상이다.
- 허용된 곳은 네이버 자체 검색 로봇(Yeti)과, 구글봇의 일부 홈 페이지(완전일치)뿐이다. 리뷰가 있는 상품 상세 페이지는 해당되지 않는다.
- 의미: robots.txt가 그 자체로 법적 구속력이 있는 것은 아니지만, **"자동 수집을 허락하지 않았다"는 사업자의 명시적 의사표시**다. 약관 위반, 부정경쟁방지법 위반 여부를 따질 때 불리한 정황이 되고, "몰랐다"는 주장이 어려워진다. 비상업·학습 목적이라는 사정은 이 의사표시를 없애지 않는다.
- 결론: **네이버 쇼핑 계열 직접 크롤링은 하지 않는 것으로 정리**한다. 다른 몰도 같은 방식으로 robots.txt를 먼저 확인하고, 전체 금지(`User-agent: *` + `Disallow: /`)이면 제외한다.

### 2. 데이터베이스 크롤링 판례
- **대법원 2022.5.12. 선고 2021도1533 (여기어때-야놀자):** 형사(저작권법 위반) 사건은 무죄. 다만 같은 사건의 **민사(서울고법)는 부정경쟁방지법 위반을 인정**해 약 10억 원 배상을 명했다. 즉 "형사 무죄 = 안전"이 아니다. ([김·신 뉴스레터](https://www.shinkim.com/kor/media/newsletter/1843), [비즈한국](https://bizhankook.com/bk/article/27377))
- **잡코리아-사람인:** 하급심에서 데이터베이스 제작자 권리 침해·부정경쟁행위가 인정되었다. 대법원 확정 여부와 사건번호는 확인하지 못했다(**확인 필요**: 대법원 종합법률정보).
- 이 사건들은 경쟁사가 상업적으로 쓴 사례다. 비상업 학습 목적에 그대로 적용되는지는 별개의 문제이고 전문가 판단이 필요하다.

### 3. 저작권 (리뷰 글 자체)
- 리뷰 글은 작성자의 저작물이 될 수 있다(짧은 글은 창작성이 부족해 보호되지 않을 수도 있음. 확인 필요).
- 한국 저작권법에는 AI 학습 전용 면책 규정이 없고, **제35조의5 공정이용**으로 판단한다. 2026.2 문체부·한국저작권위원회 안내서가 판단 요소를 정리했다(법원을 구속하지 않는 참고자료). 영리/비영리, 변형적 이용 여부, 시장 대체 여부와 함께 **수집 경위(접근 방식)도 고려**된다고 소개된다. ([신·김 뉴스레터](https://shinkim.com/kor/media/newsletter/3153))
- 비상업 학습 프로젝트는 이 요소에서 비교적 유리하지만, 면책을 보장하지는 않는다.

### 4. 개인정보
- 리뷰에는 닉네임, 지역, 사진, 구매 옵션(신체 치수 등)이 붙어 있을 수 있다. 닉네임이 단독으로는 식별성이 낮아도 다른 정보와 결합하면 개인정보가 될 수 있다.
- 개인정보보호위원회가 2025.8 공개된 개인정보를 AI 학습에 쓸 때의 안내서를 냈고, 학습 단계에서 가명·익명처리를 권고한다([Byline Network](https://byline.network/2025/08/6-277/), 원문 확인 필요).
- **수집하더라도** 작성자 식별 정보(닉네임, 이미지, 프로필, URL)는 저장하지 않는 것이 최소한의 안전장치다.

## 방법별 위험 비교

| 방법 | 법적 위험 | 데이터 품질 | 비고 |
|---|---|---|---|
| 네이버 쇼핑/스마트스토어 직접 크롤링 | **높음** (약관·차단·접근 방식) | 높음 | 비권장 |
| 다른 쇼핑몰 직접 크롤링 | 중~높음 (몰마다 약관·robots.txt 확인 필요) | 높음 | 몰별 확인 후에만 |
| GitHub 등에 올라온 크롤링 코퍼스 | 중 (출처 불명 크롤링본이면 위 위험이 그대로 이어짐, 라이선스 미표기가 많음) | 중~높음 | **평가 전용·재배포 금지**로만, 사용 전 라이선스 확인 |
| AI Hub 등 이용 조건이 명시된 공개 데이터 | **낮음** (약관 준수 시) | 중~높음 | 비상업 한정 여부, 파생 모델 배포 조건 확인 |
| 플랫폼/판매자와 합의한 데이터 | 낮음 | 높음 | 문의 필요 |
| 팀원이 직접 쓴 리뷰, LLM 생성 합성 리뷰 | 낮음 | 중 (실제 말투와 차이) | 평가에는 편향 주의 |

## 대안 (평가셋 300~500건 확보 중심)
1. **AI Hub의 한국어 감성·속성 기반 감정분석 데이터** 중 상품 리뷰 도메인이 있는지 확인하고 신청한다. 이용 조건은 데이터셋 상세 페이지에서 확인(검색으로는 조건을 확인하지 못함).
2. **팀원이 직접 한국 쇼핑몰 말투의 리뷰를 작성**해서 소량 평가셋을 만든다(긍/부정/중립, 오타·ㅋㅋ·반어 포함). 라벨은 작성자가 정한 값과 다른 사람의 검수를 함께 쓴다.
3. **LLM 합성 리뷰**를 보조로 쓴다(프로젝트 기획안에도 합성 리뷰 계획이 있음). 평가에는 보조로만 쓴다.
4. 법적으로 허용된 경로로 소량 확보되면 pseudo-label 증류와 임계값 보정에 활용한다.

## 내부 운영 원칙 (제안)
- 수집한 외부 리뷰 원문은 리포지토리·Notion에 올리지 않는다(결과 지표와 소수의 예시만).
- 작성자 식별 정보는 저장하지 않는다.
- 학습한 모델과 데이터의 출처·이용 조건을 README에 기록한다.
- 이용 조건이 불분명한 데이터는 평가 전용으로만 쓰고 학습에는 쓰지 않는다.
